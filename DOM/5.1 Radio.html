Let’s dive deep into **radio buttons** in HTML forms and how to work with them in JavaScript. --- ## **Radio Buttons** **Purpose:** Radio buttons let users select **one option from a set**. Only **one radio button in a group can be selected** at a time. --- ### **1. HTML Structure** ```html
``` **Key points:** * All radio buttons in the same **group must share the same `name`**. * Each radio button should have a **`value`** to know which option is selected. --- ### **2. Accessing Selected Radio Button in JavaScript** ```javascript const form = document.getElementById("genderForm"); form.addEventListener("submit", (e) => { e.preventDefault(); const selectedGender = document.querySelector('input[name="gender"]:checked'); if (selectedGender) { alert("Selected Gender: " + selectedGender.value); } else { alert("Please select a gender."); } }); ``` **Explanation:** * `document.querySelector('input[name="gender"]:checked')` * Finds **the radio button in the group that is currently selected**. * `.value` gives the **selected option**. * If no button is selected, `selectedGender` will be `null`. --- ### **3. Checking Radio Button Programmatically** ```javascript const maleRadio = document.querySelector('input[name="gender"][value="Male"]'); // Check the radio button maleRadio.checked = true; // Uncheck it maleRadio.checked = false; ``` --- ### **4. Listening to Change Event** You can listen for changes as the user selects a radio button: ```javascript const radios = document.querySelectorAll('input[name="gender"]'); radios.forEach(radio => { radio.addEventListener("change", (e) => { console.log("You selected: " + e.target.value); }); }); ``` **Benefit:** * Useful for **real-time updates** without submitting the form. --- ### **5.
