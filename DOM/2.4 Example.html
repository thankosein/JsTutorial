Best Practices Applied Use const for DOM elements Elements don’t change references — constants make intent clear. Prefer querySelector / querySelectorAll Flexible and supports complex CSS selectors. Cache selectors Don’t repeatedly query the DOM for the same element — it’s slow. Use textContent instead of innerHTML Safer (avoids XSS injection risks) Faster (no HTML parsing unless needed) Use forEach on NodeLists More readable and modern compared to traditional loops. Make changes in batches If adding multiple elements, consider DocumentFragment to reduce reflows.
