## **5. Forms & User Input**

Forms are how users submit data to your web page or server. JavaScript allows you to **interact with forms dynamically**, validate inputs, and respond in real time.

---

### **5.1 Accessing Form Elements**

You can access form inputs in several ways:

#### **By ID**

```html
<input type="text" id="username" placeholder="Enter username" />
```

```javascript
const username = document.getElementById("username");
console.log(username.value); // get value
```

#### **By Name**

```html
<input type="text" name="email" />
```

```javascript
const email = document.getElementsByName("email")[0];
console.log(email.value);
```

#### **By Form Reference**

```html
<form name="myForm">
  <input type="text" name="city" />
</form>
```

```javascript
const city = document.forms["myForm"]["city"].value;
```

---

### **5.2 Handling Form Submission**

By default, forms submit and reload the page. You can **prevent default behavior** and handle it with JavaScript:

```html
<form id="myForm">
  <input type="text" id="username" placeholder="Enter username" />
  <button type="submit">Submit</button>
</form>

<script>
const form = document.getElementById("myForm");

form.addEventListener("submit", (e) => {
  e.preventDefault(); // stop page reload
  const username = document.getElementById("username").value.trim();
  alert("Form submitted! Username: " + username);
});
</script>
```

---

### **5.3 Validating User Input**

Validate inputs before submitting:

```javascript
form.addEventListener("submit", (e) => {
  e.preventDefault();
  const username = document.getElementById("username").value.trim();
  
  if(username === "") {
    alert("Username cannot be empty!");
    return;
  }

  alert("Form submitted! Username: " + username);
});
```

---

### **5.4 Accessing Different Input Types**

| Input Type | Example                                              | How to access value                                            |
| ---------- | ---------------------------------------------------- | -------------------------------------------------------------- |
| text       | `<input type="text" id="name">`                      | `document.getElementById("name").value`                        |
| number     | `<input type="number" id="age">`                     | `document.getElementById("age").valueAsNumber`                 |
| radio      | `<input type="radio" name="gender" value="Male">`    | `document.querySelector('input[name="gender"]:checked').value` |
| checkbox   | `<input type="checkbox" id="agree">`                 | `document.getElementById("agree").checked`                     |
| select     | `<select id="country"><option>USA</option></select>` | `document.getElementById("country").value`                     |
| textarea   | `<textarea id="message"></textarea>`                 | `document.getElementById("message").value`                     |

---

### **5.5 Real-Time Input Handling**

You can respond as the user types:

```html
<input type="text" id="username" placeholder="Type your name" />
<p id="display"></p>

<script>
const input = document.getElementById("username");
const display = document.getElementById("display");

input.addEventListener("input", (e) => {
  display.textContent = "Hello, " + e.target.value;
});
</script>
```

### **5.6 Example: Complete Form Handling**

```html
<form id="contactForm">
  <input type="text" id="name" placeholder="Name" /><br/><br/>
  <input type="email" id="email" placeholder="Email" /><br/><br/>
  <input type="checkbox" id="subscribe" /> Subscribe to newsletter<br/><br/>
  <button type="submit">Submit</button>
</form>
<p id="result"></p>

<script>
const form = document.getElementById("contactForm");
const result = document.getElementById("result");

form.addEventListener("submit", (e) => {
  e.preventDefault();

  const name = document.getElementById("name").value.trim();
  const email = document.getElementById("email").value.trim();
  const subscribe = document.getElementById("subscribe").checked;

  if(name === "" || email === "") {
    alert("Name and Email are required!");
    return;
  }

  result.textContent = `Name: ${name}, Email: ${email}, Subscribe: ${subscribe}`;
});
</script>
```

---

### ✅ **Key Takeaways**

1. Use `e.preventDefault()` to stop default form submission.
2. Always **trim input values** to avoid unwanted spaces.
3. Validate inputs before processing.
4. Different input types require different ways to access values (`.value`, `.checked`, `.valueAsNumber`).
5. Use **real-time events** (`input`) to enhance UX.
